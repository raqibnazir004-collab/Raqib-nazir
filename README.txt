# Raqib Nazir — Portfolio Website

A minimal, motion-focused portfolio for a video editor / GFX designer.

## Edit your content
Open `index.html` and:
- Change the email address.
- Replace Instagram / YouTube / Behance / WhatsApp `href="#"` links.
- Edit project titles and descriptions.

## Add your media
Put your files inside the `media` folder:
- `profile.jpg` — main profile photo
- `project-01.mp4` — featured video
- `project-01.jpg` — optional video poster
- `project-02.jpg` — GFX sample
- `project-03.jpg` — photo-editing sample
- `project-04.mp4` — second video
- `project-04.jpg` — optional video poster

You can add more projects by copying an existing `<article class="project">...</article>` block.

## Run
Double-click `index.html` to preview it in a browser, or upload the folder to a static hosting service.
